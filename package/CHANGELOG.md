# Changelog

## 1.0.1

- Added a link for feedback and bug reports: [GitHub Issues](https://github.com/aetuss/UndisturbedBossFights/issues).

## 1.0.0

- First release: raids wait until a boss fight is over (`DelayRaids`), and no new creatures spawn near a boss fight (`BlockSpawnsNearFight`, `SpawnBlockRadius`).
- Server-to-client settings sync, `DebugLog`, `ubf_status` and `ubf_raidsoon` console commands.
